# DIRSBET — Высшая школа прогнозов

Работающий веб-прототип студенческого тотализатора на токены. **Пародия, не связана с НИУ ВШЭ.** Реальных денег, платежей, призов, аккаунтов и сетевой игры нет. Все события демонстрационные, все участники вымышленные.

## Онлайн-демо и обновления

Адрес сайта: **[mxlev.github.io/dirsbet](https://mxlev.github.io/dirsbet/)**. Исходники: [MXLev/dirsbet](https://github.com/MXLev/dirsbet).

GitHub Pages размещает статические файлы из `dist`. Workflow `.github/workflows/pages.yml` проверяет расчёты и публикует сайт после отправки изменений в `main`; его также можно запустить вручную из GitHub Actions. В настройках Pages выбран источник GitHub Actions.

Сайт работает независимо от запущенного локального сервера и компьютера автора. У каждого посетителя своё демонстрационное состояние в браузере: общих аккаунтов, событий и рейтинга пока нет. Локальное сохранение с `127.0.0.1` не переносится на адрес GitHub Pages.

## Локальный запуск

Требуется Node.js 18 или новее. Устанавливать зависимости не нужно.

```sh
cd /путь/к/dirsbet
npm start
```

Откройте **http://127.0.0.1:4173**. Для остановки нажмите `Ctrl+C` в терминале. На Mac также можно открыть `Запустить.command`.

Если порт занят: `PORT=4174 npm start`. Адрес будет http://127.0.0.1:4174. Сервер слушает только этот компьютер, не локальную сеть.

Альтернатива без Node.js:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открывать `index.html` через `file://` не нужно: браузеру требуется локальный HTTP-сервер для ES-модулей.

Игровые токены обозначены символом **Т**.

## Что работает

- Восемь сценариев: шесть открытых, один рассчитанный и один отменённый.
- Одинарные прогнозы и экспрессы из 2–5 разных событий; один исход на событие.
- Стартовые 1 000 токенов, бесплатное пополнение на 500, проверка суммы и баланса.
- Купон, история со статусами и возвратами, избранное, поиск и фильтры.
- Демонстрационная таблица лидеров. Рейтинг игрока учитывает только результат рассчитанных прогнозов, без стартового баланса и пополнений.
- Пульт симуляции: выбор исхода, отмена события, автоматический расчёт связанных прогнозов, сброс демосессии.
- Сохранение в `localStorage` и обновление интерфейса при изменениях в другой вкладке.
- Адаптивные десктопная и мобильная версии; мобильный купон открывается нижней панелью.
- Управление с клавиатуры, видимый фокус, модальные окна, поддержка reduced motion.

## Как проверить полный цикл

1. Выберите «Да, можно спать» в событии про пару Дани.
2. В купоне оставьте 100 Т и зафиксируйте прогноз. Баланс станет 900 Т.
3. Откройте «Пульт симуляции», выберите то же событие и исход «Да, можно спать».
4. Зафиксируйте исход. Баланс станет 1 085 Т, история покажет возврат 185 Т и статус «Зашёл».
5. Обновите страницу: состояние сохранится.

В экспрессе все исходы должны совпасть. При отмене одного события его коэффициент становится 1.00; при отмене всех возвращается исходная сумма. Коэффициент произведения округляется до сотых перед расчётом возврата. Одно событие рассчитывается только один раз. Для нового круга есть сброс демосессии.

```sh
npm test
```

## Проверено

- 14 автоматических проверок расчётов и восстановления состояния проходят.
- В браузере проверены одинар, экспресс с отменой одного события, начисление, история, перезагрузка, поиск, избранное, демобонус и сброс.
- На ширинах 320, 390 и 430 px нет горизонтального переполнения страницы. Кнопка пополнения использует центрированный SVG-плюс.

## Данные и ограничения

Сохранение находится только в браузере под ключом `pirsbet.local.v1`. Этот технический ключ сохранён после переименования в DIRSBET, чтобы не терять существующие баланс и историю. Сброс демосессии очищает игровой прогресс этого прототипа. Смена браузера, адреса или порта создаёт отдельное сохранение. При недоступном хранилище приложение показывает предупреждение и продолжает текущую сессию в памяти. Повреждённые данные заменяются новым демосостоянием с предупреждением.

Нет серверной базы, авторизации, проверок подлинности локальных очков или синхронизации между устройствами. Для локальной демонстрации это намеренно: пользователь может редактировать собственные данные браузера. Ники в рейтинге и сценариях вымышленные. Формы добавления реальных студентов нет.
